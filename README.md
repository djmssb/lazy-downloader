# 懒洋洋下载器

中文安卓视频、音频与动态照片下载器。手机直接解析和下载，支持四种玻璃配色。

[下载最新版](https://github.com/djmssb/lazy-downloader/releases/latest)

Android 8.0 及以上；小米 15 Pro 选择 arm64-v8a，其他手机可用 universal。先手动安装一次支持在线更新的新版，之后打开 App 或点击“检查版本更新”。安装由手机系统确认。

对应源码、GPL 许可和上游组件说明随每个发行版的 lazy-downloader-source.zip 提供。仓库不保存签名密钥或用户下载内容。
